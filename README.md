# 🟢 Node.js Akademi

Kurulum gerektirmeyen, sıfırdan ileri seviyeye Node.js öğreten interaktif uygulama.
Tek bir `index.html` dosyasıdır — tarayıcıda açman yeterli.

## Özellikler

- **29 ders** — Başlangıç, Orta, İleri ve Araçlar seviyeleri
- **Tarayıcıda Node laboratuvarı** — `fs`, `path`, `http`, `events`, `stream`, `crypto`, `util`, `os`, `Buffer`, `process` simülasyonu; `require`/`import`, top-level `await`, kendi HTTP sunucuna `fetch`
- **Görevler ve mini sınavlar** — çıktı otomatik kontrol edilir, ilerleme tarayıcıda saklanır
- **🩺 Kod Doktoru** — yapıştırdığın kodu analiz eder, yaygın hataları gerekçesiyle düzeltir ve fark (diff) gösterir
- **Araç rehberleri** — Node kurulumu, terminal, VS Code, npm, hata ayıklama, proje yapısı, Git, Docker

## Kullanım

`index.html` dosyasını tarayıcıda aç. Veya GitHub Pages ile yayınla:
Settings → Pages → Branch: `main` / root.

> Laboratuvar gerçek Node değil, eğitim amaçlı bir simülatördür; npm paketleri çalışmaz.
